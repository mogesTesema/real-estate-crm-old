# **1\. Super Admin**

**Access Level:** Full system control

**Key Functions:** System configuration, user management across all tenants, security, billing, audit logs

***Activities & Work***

| Activity | Description |
| :---- | :---- |
| **Tenant Management** | Create, suspend, or delete company/tenant accounts |
| **User Management** | Create/delete users across all tenants, assign roles |
| **System Configuration** | Global settings, system-wide defaults, feature toggles |
| **Security Management** | Configure MFA, password policies, IP whitelisting |
| **Audit Log Review** | Monitor all system activities, user actions, security events |
| **Subscription/Billing** | Manage plans, pricing, process payments, generate invoices |
| **Integration Management** | Configure API keys, webhooks, third-party connectors |
| **Data Backup** | Configure and monitor automated backups, disaster recovery |
| **Performance Monitoring** | View system health, usage analytics, server metrics |
| **Support Access** | View support tickets, provide system-level assistance |

**2\. Branch/Team Manager**  
**Access Level:** Branch-wide

**Key Functions:** Manages Broker/Agency Owners, team performance, branch revenue, lead routing

***Activities & Work***

| Activity | Description |
| :---- | :---- |
| **Broker Management** | Approve/register new Broker/Agency Owners under their branch |
| **Team Oversight** | Monitor all Brokers and their Agents' performance |
| **Branch Reports** | View revenue, closed deals, commission summaries per branch |
| **Lead Routing Rules** | Configure round-robin, territory, or workload-based lead distribution |
| **KPI Monitoring** | Track conversion rates, response times, team goals |
| **Commission Oversight** | Review and approve commission structures across Brokers |
| **Performance Reviews** | Generate team leaderboards, identify top performers |
| **Conflict Resolution** | Resolve disputes between Brokers or Agents |
| **Branch Settings** | Configure localization, currency, tax rules per branch |
| **Inventory Oversight** | Monitor all listings and projects across the branch |

 

# **3\. Broker/Agency Owner**

**Access Level:** Agency-wide

**Key Functions:** Manages Sales/Leasing Agents, agency revenue, commissions, team performance

***Activities & Work***

| Activity | Description |
| :---- | :---- |
| **Agent Management** | Register/approve new Sales/Leasing Agents under their agency |
| **Agency Dashboard** | View agency revenue, GCI, closed deals, active listings |
| **Lead Assignment** | Configure lead distribution rules for their agents |
| **Commission Plans** | Create and manage commission structures (flat, tiered, splits) |
| **Performance Tracking** | Monitor each agent's pipeline, conversion, and performance |
| **Inventory Management** | Oversee all agency listings, projects, and inventory aging |
| **Financial Oversight** | Track invoices, payments, commission payouts |
| **Client Management** | View high-value clients, VIP contacts, referral sources |
| **Marketing Oversight** | Approve campaigns, review marketing ROI |
| **Reporting** | Generate agency-wide reports for stakeholders |

**4\. Sales/Leasing Agent**  
**Access Level:** Personal only

**Key Functions:** Lead capture, property showings, deal progression, client communication

***Activities & Work***

| Activity | Description |
| :---- | :---- |
| **Lead Management** | Capture leads from all channels, follow up, convert to opportunities |
| **Client Communication** | Call, email, SMS, WhatsApp with buyers/sellers/tenants |
| **Property Viewings** | Schedule and conduct property showings, capture feedback |
| **Location Tracking** | MANDATORY: Check-in at viewings, GPS tracking for compliance |
| **Deal Progression** | Move deals through pipeline stages (Kanban) |
| **Listing Management** | Create and update property listings with photos and details |
| **Calendar Management** | Schedule viewings, meetings, tasks, sync with calendar |
| **Documentation** | Generate offers, contracts, upload documents |
| **Task Management** | Complete daily tasks, follow-ups, to-do items |
| **Performance Monitoring** | View personal KPIs, goals, commission projections |
| **Lead Scoring** | Prioritize hot leads based on engagement and AI scoring |
| **Client Portal** | Manage client access to documents and deals |

**5\. Property Manager**  
**Access Level:** Managed properties only

**Key Functions:** Lease management, tenant communication, maintenance, rent collection

***Activities & Work***

| Activity | Description |
| :---- | :---- |
| **Property Assignment** | MANDATORY: Every property must have a dedicated Property Manager |
| **Lease Management** | Create, renew, and terminate lease contracts |
| **Tenant Management** | Onboard tenants, process applications, screening |
| **Rent Collection** | Generate recurring invoices, track payments, flag late payments |
| **Maintenance Requests** | Receive, assign, and track work orders to completion |
| **Vendor Management** | Manage contractors, vendors, service providers |
| **Property Inspections** | Schedule move-in/move-out inspections, condition reports |
| **Landlord Reporting** | Generate owner statements, revenue reports, property performance |
| **Occupancy Management** | Track vacancy rates, optimize rental pricing |
| **Utility Management** | Track utility meters, billbacks to tenants |
| **Compliance** | Ensure properties meet regulatory requirements |
| **Renewal Management** | Handle lease renewals, rent increases, negotiations |

**6\. Marketing Staff**  
**Access Level:** Marketing only

**Key Functions:** Campaign creation, lead nurturing, landing pages, social media ads

***Activities & Work***

| Activity | Description |
| :---- | :---- |
| **Campaign Creation** | Build email/SMS drip campaigns, lead nurturing sequences |
| **Landing Pages** | Create no-code landing pages and property microsites |
| **Email Marketing** | Design templates, manage lists, track open/click rates |
| **Social Media Ads** | Create/manage Facebook/Instagram/Google ad campaigns |
| **Lead Generation** | Capture leads from ads, landing pages, social media |
| **SEO Optimization** | Manage public property portal, optimize for search |
| **Content Management** | Create property descriptions, blog posts, newsletters |
| **Analytics** | Track campaign ROI, lead source performance |
| **Segmentation** | Create targeted audience segments based on behavior |
| **Brand Management** | Ensure brand consistency across all marketing materials |
| **Integration** | Connect with social platforms, email services, analytics tools |
| **Report Generation** | Marketing performance reports, budget tracking |

**7\. Finance Staff**  
**Access Level:** Financial only

**Key Functions:** Commission processing, invoicing, financial reporting, reconciliation

***Activities & Work***

| Activity | Description |
| :---- | :---- |
| **Commission Processing** | Calculate agent commissions, review, approve, process payouts |
| **Invoicing** | Generate and send invoices to clients, track payments |
| **VAT/Tax Management** | Apply correct tax rates, generate VAT/sales tax reports |
| **Payment Tracking** | Record receipts, match payments to invoices |
| **Reconciliation** | Reconcile bank statements, trust accounts, clearing accounts |
| **Financial Reporting** | P\&L statements, revenue reports, commission summaries |
| **Agent Payouts** | Process agent commission payments, track payment status |
| **Escrow Management** | Track security deposits, trust account balances |
| **Audit Preparation** | Provide financial records, transaction history |
| **Integration** | Export data to external accounting systems (QuickBooks, Xero) |
| **Budget Monitoring** | Track agency expenses against budgets |
| **Compliance** | Ensure financial compliance with real estate regulations |

**8\. Portal User**  
**Access Level:** Limited, own data only

**Key Functions:** View own deals, documents, maintenance (tenant), property performance (landlord)

***TENANT Activities***

| Activity | Description |
| :---- | :---- |
| **View Lease** | View active lease agreement, terms, and conditions |
| **Rent Payments** | View payment history, make rent payments online |
| **Maintenance** | Submit maintenance requests with photos, track status |
| **Documents** | View and download shared documents and contracts |

 

***LANDLORD Activities***

| Activity | Description |
| :---- | :---- |
| **Property Dashboard** | View property performance, occupancy, rental income |
| **Rent Statements** | View rent collected, fees deducted, net remittance |
| **Lease Management** | View active leases, tenants, renewal dates |
| **Financial Reports** | View property revenue reports, expense tracking |

 

***BUYER/SELLER Activities***

| Activity | Description |
| :---- | :---- |
| **Property Search** | Search properties, save searches, view matched properties |
| **Favorites** | Save favorite properties, track listing changes |
| **Deal Tracking** | View active offers, contracts, closing status |
| **Documents** | View and sign documents, download contracts |

 

***COMMON Activities***

| Activity | Description |
| :---- | :---- |
| **Profile Management** | Edit personal details, notification preferences |
| **Communication** | View messages from agents, property managers |
| **Notifications** | Receive alerts on deals, lease expirations, payments |
| **Schedule** | View upcoming viewings, meetings, appointments |

 

**9\. Activity Matrix Summary**

| User Role | Primary Work | Key Metrics |
| :---- | :---- | :---- |
| **Super Admin** | System configuration, tenant management, security | System uptime, user count, revenue |
| **Branch Manager** | Manage Brokers, team oversight, branch performance | Branch revenue, broker performance |
| **Broker/Owner** | Manage Agents, agency revenue, commission | Agency GCI, agent performance |
| **Sales Agent** | Lead capture, client communication, deal progression | Leads, conversions, closed deals |
| **Property Manager** | Lease management, maintenance, rent collection | Occupancy rate, rent collection |
| **Marketing Staff** | Campaigns, landing pages, lead generation | Leads generated, ROI |
| **Finance Staff** | Commission, invoicing, reconciliation | Commission paid, revenue |
| **Portal User** | Self-service, documents, deals | n/a |
